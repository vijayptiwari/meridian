Portals

Meridian uses local Playwright to search LinkedIn and Naukri. Sessions persist on disk so you only log in once per portal.

First login

  1. Enable Headed browser in the run panel
  2. Start a search run from the dashboard or CLI
  3. Log in manually when the browser window opens
  4. Sessions are saved to data/browser-state/

Enable or disable portals

In src/config.json:

{
  "portals": {
    "linkedin": { "enabled": true },
    "naukri": { "enabled": true }
  }
}

CLI flags

JOB_AGENT_PORTAL=linkedin npm run search
JOB_AGENT_HEADED=true npm run search

Assisted apply

Use npm run assist-apply for human-in-the-loop submissions. Meridian prepares forms and content; you confirm before sending.

Important: Portal UIs change frequently — selectors may need maintenance in the open-source adapters. Respect platform rate limits and terms of service.
