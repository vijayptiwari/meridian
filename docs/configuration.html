Configuration

Meridian reads src/config.json. Copy from src/config.example.json on first install. You can edit via the Settings panel in the UI or directly in the file.

Config sections

Section Purpose
profile Name, skills, titles, resume summary
preferences Search queries, score threshold, easy apply toggles
locationPolicy Expected physical location for hybrid / WFO roles
salary Compensation filters and research inputs
transition Career transition mode inputs
gmail Gmail cleanup settings and token directory
portals Enable or disable LinkedIn and Naukri
llm Provider, model, base URL, webhook URL

Environment variables

See .env.example in the repository. Environment variables override config for LLM keys and runtime flags such as:

  • JOB_AGENT_MODE — search, assist-apply, demo, next-role, etc.
  • JOB_AGENT_HEADED — launch visible browser for portal login
  • JOB_AGENT_PORTAL — linkedin, naukri, or both
  • JOB_AGENT_UI_HOST — dashboard bind address (default 127.0.0.1)
  • OPENAI_API_KEY, OPENAI_BASE_URL, OPENAI_MODEL

Security

  • Never commit src/config.json, .env, or credentials.json
  • The UI listens on 127.0.0.1 by default — do not expose it to the public internet without a reverse proxy and auth
  • Browser session state is stored in data/browser-state/ — treat it like a password
