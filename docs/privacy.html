Privacy model

Meridian is local-first. The dashboard binds to 127.0.0.1 by default.

Stays on your machine

  • Resume files and tailored outputs (resume/, data/output/)
  • Browser session state for LinkedIn/Naukri (data/browser-state/)
  • Run history, tracker state, wizard progress, checkpoints, and active-run snapshots (data/ui/)
  • API keys in src/config.json and .env

May leave your machine (optional)

  • LLM API requests when you configure OpenAI-compatible, Ollama, or webhook providers
  • Portal pages loaded in Playwright during job research (standard HTTPS to LinkedIn/Naukri)

Keyword-only mode

Choose Keyword-only in Settings to score and shortlist without any LLM API calls — useful for zero-cost runs.
