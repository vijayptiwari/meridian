Troubleshooting

Playwright / install

Run npm run init or npx playwright install chromium, then npm run doctor.

Portal login

Enable Headed browser in the dashboard, run search, and complete login manually. Use Check portal selectors in run history or npm run doctor -- --portals.

LLM failures

Test connection in Settings. Try keyword-only mode or the Ollama preset (http://127.0.0.1:11434/v1).

Config / resume

Copy src/config.example.json to src/config.json. Upload a resume in the Get started section at the top of the dashboard, or edit profile in Settings (Profile · Search & run · LLM).

Interrupted runs / resume

If the UI server restarts while a run was in progress, Meridian marks it interrupted when a checkpoint exists. Open the Runs tab and click Resume from checkpoint, or use the banner on the dashboard. To re-run with the same settings after success or failure, use Replay run.

Page refresh alone does not stop the worker — the UI reconnects automatically. Checkpoints live in data/ui/checkpoints/.

Dashboard won't start (port in use)

Another npm run ui process may still be bound to port 3030. Stop it or set JOB_AGENT_UI_PORT in the environment. On Windows, find the process with Get-NetTCPConnection -LocalPort 3030.
