Product roadmap

Meridian is evolving toward a local career ops system you can trust and use daily. See ROADMAP.md in the repository for the full scorecard and KPIs.

v0.2 — Credible and demoable

  • First-run wizard with demo in step 2
  • Match panels and score explanations on job cards
  • Portal ToS acknowledgment and privacy diagram
  • Marketing headline and GitHub social proof

v0.3 — Sticky workflow

  • Application tracker (saved → applied → interview → offer → rejected)
  • Resume diff view and email-apply drafts
  • Shortlist sort/filter and portal selector health checks
  • Ollama one-click preset

v0.4 — Trust and growth

  • Run compare, export/import bundle, outcome loop
  • Troubleshooting hub, architecture docs, docs search
  • npm run init one-command setup
  • Tagged releases and contributor guide
