Quickstart

Meridian runs entirely on your machine. Clone the repository, copy the config templates, install dependencies, and open the dashboard at http://127.0.0.1:3030.

Prerequisites

  • Node.js 20 or later
  • npm
  • Chromium via Playwright (installed below)
  • Optional: an OpenAI-compatible API key or local Ollama instance

1. Clone and configure

git clone https://github.com/vijayptiwari/meridian.git
cd meridian
cp src/config.example.json src/config.json
cp .env.example .env

2. Install dependencies

npm install
npx playwright install chromium
npm run doctor

npm run doctor verifies Node version, config files, and module integrity. Fix any reported issues before continuing.

3. Start the dashboard

npm run ui

Open http://127.0.0.1:3030 in your browser. No login screen — the dashboard loads immediately.

4. Set up your profile

  1. Open Settings in the sidebar
  2. Enter your name, skills, target titles, and search queries
  3. Or upload a resume on the intake panel — Meridian extracts text locally

5. Configure LLM (optional)

Add to .env:

OPENAI_API_KEY=sk-...

For Ollama on localhost:

OPENAI_BASE_URL=http://localhost:11434/v1
OPENAI_MODEL=llama3.1

Skip this step to use keyword-only mode — deterministic scoring with no API calls. See LLM providers.

6. Run your first pipeline

  • Try Demo — generates sample jobs and shortlist output without portal access
  • Run Jobs Dashboard — full pipeline; enable Headed browser on first run to log into LinkedIn or Naukri manually

CLI alternatives

npm run search
npm run assist-apply
npm run demo

Windows PowerShell:

.\run-agent.ps1 -Mode search -Headed

macOS / Linux:

bash scripts/run-agent.sh both search

Outputs

Results are saved under data/output/:

  • jobs-*.json, shortlist-*.json, agent-report-*.json
  • Tailored resumes in data/output/tailored-resumes/
  • CSV export from the dashboard for any run with a shortlist

Docker (optional)

cp src/config.example.json src/config.json
docker compose up --build
