Gmail cleanup

Optional feature to preview, trash, or delete promotional Gmail messages. OAuth tokens are stored locally — never sent to a Meridian server because there isn't one.

Setup

  1. Enable Gmail API in Google Cloud Console
  2. Create OAuth Desktop app credentials
  3. Save as credentials.json in the project root
  4. Set gmail.enabled: true in config

Run from CLI

npm run gmail:preview
npm run gmail:trash

Dashboard

Use the Gmail Cleanup panel in the Meridian UI for preview and batch actions with a visual workflow.

Tokens are stored in data/gmail/ (configurable via gmail.tokenDir).

Never commit credentials.json or the data/gmail/ token directory.
