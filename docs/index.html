A complete platform for modern job search

Meridian replaces fragmented tools with one disciplined workflow — from discovery through preparation, with the reliability professionals expect from production software.

01

Multi-agent orchestration

Dedicated agents for research, compensation, fit analysis, resume editing, and interview prep — each stage optimized for its task.

02

Get started in three steps

Upload a resume, choose Find jobs / Upskill / Change career, and start analysis from one screen — with Settings for profile, portals, and LLM when you need them.

03

Runs that survive refresh

Page refresh reconnects to live runs. Checkpoints let you resume after an interrupt or replay a finished run with the same settings.

04

Provider-neutral AI

Connect OpenAI, Azure, Groq, or a local Ollama instance. Switch providers without migrating your data or workflow.

05

Controlled automation

Browser automation runs locally with human oversight. You review every submission before it leaves your machine.

06

Career planning modes

Beyond active search — plan role transitions, identify skill gaps, and build structured upskilling paths.

07

Demo before deploy

Evaluate the full interface with sample data before connecting job portals or API credentials.
