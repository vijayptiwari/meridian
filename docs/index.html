Built for operators, not passive job boards

Most tools either dump listings, spam applications, or lock your profile in a paid cloud. Meridian orchestrates a full career workflow on hardware you control.

01

Multi-agent pipeline

Specialized agents for research, compensation, fit analysis, resume modification, and interview prep — not a single generic chat box.

02

Local web dashboard

Run npm run ui and manage searches, shortlists, exports, and settings from a premium dashboard at 127.0.0.1:3030.

03

Bring your own model

OpenAI-compatible APIs, local Ollama, Groq, Azure, or a custom webhook. Switch providers without rewriting the product.

04

Assisted apply, not blind bots

Playwright runs in headed mode when you need it. You stay in control of submissions and platform logins.

05

Upskilling & transition modes

Plan your next role or pivot industries with dedicated agent workflows beyond basic job search.

06

Try before you connect portals

Demo mode generates sample output so you can explore the UI before linking LinkedIn or Naukri.

Who Meridian is for

  • Engineers and operators running an active search on LinkedIn or Naukri
  • Privacy-conscious professionals who refuse to upload resumes to random SaaS tools
  • Power users who want Ollama or their own LLM stack
  • Contributors who want an open, hackable agent framework

What you get on day one

  • Shortlist scoring with configurable thresholds
  • Tailored resume drafts exported to data/output/
  • CSV export from the dashboard
  • Setup checklist and npm run doctor health checks
  • Optional Gmail cleanup with local OAuth tokens

How it works

Three steps from clone to your first shortlist.

A

Install locally

Clone the repo, copy config templates, install Node dependencies and Playwright Chromium.

B

Configure profile & LLM

Upload a resume or edit skills in Settings. Add an API key — or run keyword-only mode for free.

C

Run the pipeline

Start with Demo mode, then run a headed search to log into portals and build your shortlist.
